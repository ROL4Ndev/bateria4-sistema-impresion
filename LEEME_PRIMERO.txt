EJECUTAR DESDE ESTA CARPETA
python sistema_impresion.py
python sistema_impresion.py --demo
python sistema_impresion.py --pruebas

En Windows también puedes usar py en lugar de python.

ORGANIZACIÓN MODULAR
main.py: punto de entrada para desarrollar y ejecutar por módulos.
impresion/: seis clases, interfaz de consola y pruebas separadas.
herramientas/generar_entrega.py: reúne los módulos en sistema_impresion.py.
.github/workflows/verificar.yml: comprobaciones automáticas en GitHub.

La guía exige UN archivo .py para Canvas. Entregar sistema_impresion.py.
Para trabajar por módulos: python main.py
Para generar la entrega: python herramientas/generar_entrega.py
Después ejecutar las pruebas de ambas versiones.

El informe, las diapositivas y las imágenes describen el archivo oficial,
que conserva exactamente el mismo código y los mismos números de línea.
